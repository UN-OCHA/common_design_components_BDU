## Accessibility baseline

Every part of the system targets **WCAG 2.1 AA** as a minimum: each brand colour ships a dedicated accessible text variant, all interactive elements have keyboard navigation and visible focus, and RTL (right-to-left) languages are supported. Full notes live on each component and foundation page.
