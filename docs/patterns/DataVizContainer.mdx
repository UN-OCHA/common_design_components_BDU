# Data viz container

The standard wrapper every OCHA chart sits inside — title, optional subtitle, the chart area, a dated source line, and an optional footnote. It is the connective tissue between the [Data visualization](?path=/docs/foundations-data-visualization--docs) foundation and the products that consume it.

## When to use

- **Always.** Any chart shipped in an OCHA product — dashboard card, report figure, social graphic, or standalone export — sits in this wrapper.
- You need the chart to **carry its own title and source** so it stays legible when lifted out of context (screenshotted, embedded, reshared).
- The finding needs a **subtitle** to add the unit or scope, or a **footnote** to spell out acronyms and caveats.
- **Use something else when** you only have a single headline number — that is the *Key figures (text)* format (still wrapped, but no chart area); see the [Data visualization](?path=/docs/foundations-data-visualization--docs) chart picker.

When this container is dropped into a product, the outer frame is a real component: a `cd-card` on a [Dashboard shell](?path=/docs/patterns-dashboard-shell--docs), or a `<figure>` inside `cd-article` on a [Report page](?path=/docs/patterns-report-page--docs). The five parts above stay the same in both.

## Structure

```html
<figure class="cd-card">
  <div class="cd-card__container">

    <!-- Title: state the finding -->
    <h3 class="cd-card__title">Funding gap widens across top sectors</h3>

    <!-- Optional subtitle: unit + scope -->
    <p class="cd-caption">Requirements vs. received, 2026 (US$ million)</p>

    <!-- Chart area: build to the chart's foundation spec -->
    <div class="cd-card__description">
      <svg viewBox="0 0 250 150" role="img"
           aria-label="Funding by sector, 2026. Food 512, Health 361, WASH 258, Shelter 174, Protection 120 (US$ million).">
        <!-- bars: fill #009EDB, sharp corners, sorted by value -->
      </svg>
    </div>

  </div>

  <!-- Source line (required) + optional footnote -->
  <figcaption class="cd-card__footer">
    <div class="cd-caption">Source: OCHA, FTS, as of 30 Sep 2026.</div>
    <div class="cd-caption"><em>WASH: Water, Sanitation and Hygiene. Figures rounded.</em></div>
  </figcaption>
</figure>
```

Inside `cd-article` the same parts wrap as a plain figure:

```html
<figure>
  <h3 class="cd-block-title">Funding gap widens across top sectors</h3>
  <p class="cd-caption">Requirements vs. received, 2026 (US$ million)</p>
  <img src="funding-by-sector.svg"
       alt="Funding by sector, 2026: Food 512, Health 361, WASH 258, Shelter 174, Protection 120 (US$ million).">
  <figcaption class="cd-caption">Source: OCHA, FTS, as of 30 Sep 2026.</figcaption>
</figure>
```

Every chart **must** carry a text alternative — an `aria-label` / `alt` summarising the finding, or an adjacent data table — per the Data visualization [accessibility rules](?path=/docs/foundations-data-visualization--docs).

## Responsive

The container is fluid; the chart inside it scales with an SVG `viewBox`. Values from `tokens/brand.css`.

- **Below `--cd-bp--sm` (576px)** — full-width container with `--cd-container-padding` (12px). Title may wrap to two lines; keep the subtitle and footnote, they carry context a small chart can't. Let the SVG `viewBox` scale the chart to the column width — never set a fixed pixel width.
- **`--cd-bp--md` (768px)** — when used as a `cd-card` in a 2-up `cd-grid`, the container takes half the row; design the chart to read at roughly 360–420px wide (the breakpoint the [Horizontal bar](?path=/docs/foundations-data-visualization-horizontal-bar--docs) spec is tuned for).
- **`--cd-bp--lg` (1024px) and up** — inside `cd-article` the container holds at `--cd-max-content-width` (820px); on a dashboard it sizes to its grid cell. Past `--cd-bp--xl` (1200px), keep charts within their cell rather than stretching — wide bars read as exaggerated.
