# Resources

Everything you need to build with the OCHA Design System in one place — logos, design tokens, the AI rules file, icon libraries, and tooling.

## Logo

Use the **blue** logo on light backgrounds and the **white** logo on dark or photographic backgrounds. Never recolour, distort, or translate the wordmark. See **Foundations → Logo** for clear-space and minimum-size rules.
